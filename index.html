Welcome — what this tool does

      
REIT Strategist helps you find, research, and invest in REITs (Real Estate Investment Trusts) — companies that own real estate (malls, apartments, data centers, etc.) and pay you dividends from the rent they collect. Think of it as your personal REIT research assistant: it pulls live market data and news, uses AI to analyze each REIT, and helps you place trades at your broker.

      
You don't need to be an expert. The tool explains everything in plain English. You tell it your goals (income vs. growth, how much cash you have), and the AI agents do the heavy lifting — screening, analysis, ranking, and order suggestions.

    


    

      
Getting started in 5 minutes

      
    
        
  1. Get a free Finnhub API key — go to finnhub.io, sign up, copy your API key. This is what powers the live stock prices and news. Free tier is fine.
    2. 
        
  2. Get at least one AI key — the easiest is Groq (free at console.groq.com, very fast). For smarter analysis, add Claude (anthropic.com) or ChatGPT (platform.openai.com). You can start with just Groq and add more later.
    3. 
        
  3. Go to Settings — paste your Finnhub key and your AI key(s). Click Save.
    4. 
        
  4. Run the Screener — go to the Screener tab, pick a sector (or "All sectors"), set a minimum dividend yield (try 3%), and click "Discover REITs." The tool fetches live prices + recent news for 24 REITs and writes a 1-sentence thesis for each.
    5. 
        
  5. Deep-dive any REIT — click "Watch" on any candidate to load its price chart, then click "Run Analyst Agent" for a full research report with a Buy/Hold/Avoid verdict.
    6. 
      

      
That's the basics. The other tabs (Best Picks, Trade, Portfolio, Income) build on this — explained below.

    


    

      
How to use this tool in MOCK mode (safe testing, no real money)

      
Start here if you're new. Mock mode lets you test the entire tool — screening, analysis, trade suggestions, portfolio tracking — without risking any real money. Everything works the same; the only difference is trades are "paper" (fake).

      
    
        
  1. Open a free Alpaca paper trading account — go to app.alpaca.markets, sign up, and choose "Paper Account." You get $100,000 in fake money to practice with. No credit card, no risk.
    2. 
        
  2. Get your Alpaca API keys — in Alpaca dashboard, go to "Your API Keys." Copy the Key ID and Secret.
    3. 
        
  3. Add them to this tool — Settings tab → "Broker API keys" section → paste Alpaca Key ID and Secret → Save.
    4. 
        
  4. Connect — Trade tab → select "Alpaca — Paper trading" → click "Connect & load account." You'll see your $100,000 paper balance.
    5. 
        
  5. Practice the full workflow: Run the Screener → pick a REIT &rgt; run the Analyst → go to Best Picks for top 3 → use the Order Router Agent to suggest a trade → click "Place order" — it executes in your paper account instantly. Check Portfolio and Income tabs to see how your fake holdings perform.
    6. 
      

      
Why start here? You can test the AI's recommendations for weeks without risk. When you trust the system, switch to live mode (below). Paper trading is how professional traders learn — there's no shame in spending a month here.

    


    

      
How to use this tool in LIVE mode (real money)

      
Only switch to live mode after you've paper-traded for at least 2-4 weeks and you're comfortable with how the AI agents behave. Real money means real risk.

      
You have two options for live trading:

      
Option A — Fully automated (Alpaca Live or Tradier Live):

      
    
        
  1. Open a live brokerage account at alpaca.markets or tradier.com. Fund it with real money.
    2. 
        
  2. Get your live API keys from their dashboard.
    3. 
        
  3. Add them to Settings → Broker API keys → Save.
    4. 
        
  4. Trade tab → select "Alpaca — Live" or "Tradier — Live" → Connect. The tool will warn you that this is real money.
    5. 
        
  5. When you click "Place order," the trade executes at your broker with real money. Always review the Order Router Agent's suggestion before placing.
    6. 
      

      
Option B — Manual at Fidelity (or any broker without an API):

      
    
        
  1. Select "Fidelity — Manual (no API)" in the Trade tab broker dropdown.
    2. 
        
  2. Click "Import CSV positions" to upload your Fidelity positions export (from Fidelity.com → Portfolio → Positions → Download). The tool parses it automatically — money market funds like SPAXX are filtered out.
    3. 
        
  3. Use the Order Router Agent as normal — it sees your Fidelity positions and sizes recommendations accordingly.
    4. 
        
  4. When you click "Place order," the tool shows a copyable summary (symbol, side, quantity, order type, limit price, TIF). Click "Copy to clipboard," then click "Open Fidelity.com →" and paste the details into Fidelity's order ticket. No real API needed — you're just using the AI for research and the tool for tracking.
    5. 
      

      
Why no Fidelity API? Fidelity doesn't offer a public brokerage API for individual investors — only for registered investment advisors. This is a Fidelity policy, not a limitation of this tool. Same applies to Schwab, Robinhood, and Vanguard. If you want full automation, use Alpaca or Tradier; if you want Fidelity's great service and research, use manual mode.

    


    

      
Understanding the 4 AI agents (in plain English)

      
The tool has four AI "agents" — each does a specific job. You can use them in order (Screener → Analyst → Best Picks → Trade) or jump to whichever you need:

      
    
        
  • Discovery Agent (Screener tab) — "Find me REITs that match my criteria." Pulls live prices + recent news for 24 REITs and writes a 1-sentence thesis for each. Fast — usually done in 10-20 seconds.
    • 
        
  • Analyst Agent (Watch & Analyst tab) — "Write me a research report on this REIT." Loads any ticker's chart + fundamentals + recent news, then produces a Dividend Safety Score (1-10), Growth Outlook, Key Risks, and a Buy/Hold/Avoid verdict. Takes 15-30 seconds.
    • 
        
  • Tactical Agent (Best Picks tab) — "What should I buy right now?" Looks at your current portfolio, your cash, your risk profile, and ranks the top 3 REITs to buy today — with suggested allocation % and entry strategy. Takes 30-60 seconds.
    • 
        
  • Order Router Agent (Trade tab) — "What's the best way to place this trade?" Looks at the current price, your broker account, and any Analyst verdict, then recommends the order type (market/limit/stop), quantity, limit price, and timing. Pre-fills the order ticket for you.
    • 
      

    


    

      
How the AI models work together

      
The tool uses a tiered system — fast lightweight models do the easy work, and stronger models do the heavy lifting and verify the output:

      
    
        
  • Groq (fast, lightweight) — does the easy work: screener theses, simple summaries. Very fast (500+ words/sec), free tier generous. Think of it as the research assistant who gathers info quickly.
    • 
        
  • Claude, ChatGPT, DeepSeek, GLM (strong, thorough) — do the heavy lifting: analyst verdicts, tactical rankings, order routing. These models verify the analysis and make the final call. Think of them as the senior analysts who review the assistant's work.
    • 
      

      
You only need one AI key to start. If you only have Groq, it'll do everything (but the heavy analysis won't be as deep). If you add Claude or ChatGPT, the tool automatically uses Groq for simple tasks and the stronger model for complex ones — with automatic fallback if any provider fails. Add as many as you have for maximum reliability.

Where the data comes from (web search feature)

      
Live prices & fundamentals — Finnhub API (uses your key). Real-time quotes, dividend yield, payout ratio, debt/equity. Updated every time you run a screen or load a ticker.

      
Recent news (the "web search") — Finnhub's company-news endpoint pulls the 5 most recent news articles for each ticker from the last 30 days. These headlines + summaries are passed to the AI agents so their analysis reflects current events (earnings, dividend changes, acquisitions, downgrades), not just training-data knowledge. The Screener and Analyst both use this — you'll see "N news items" badges on the output.

      
Price charts — Finnhub first (paid plans), then Yahoo Finance (free, no key) as automatic fallback. If both fail, a clean today-snapshot panel is shown instead of an error.

      
Dividend history — Finnhub's /stock/dividend2 (uses your key) with Yahoo Finance via CORS proxy as fallback. Powers the Income tab's 10-year history, CAGR, streaks, and ex-dividend predictions.

    


    

      
REIT dividend tax treatment (US) — important

      
REIT dividends are not "qualified dividends" — they're taxed as ordinary income at your normal tax rate (up to 37%) plus a 3.8% surtax if you earn over $200k (single) / $250k (married). This is different from regular stock dividends, which get a lower rate (0/15/20%).

      
What this means for you: (1) Hold REITs in an IRA or Roth IRA when possible — this skips the tax drag entirely. (2) The "yield" you see in this app is pre-tax — subtract your tax rate to see what you actually keep. (3) Some REIT dividends are "return of capital" which is tax-deferred (lowers your cost basis, taxed later when you sell). Check the REIT's investor relations page for their annual tax letter.

      
This is general info, not tax advice — talk to a CPA for your situation.

    


    

      
Brokers that work with this tool

      
Alpaca (paper + live) — best for testing and automation. Free paper account with $100k fake money. Get keys at app.alpaca.markets. CORS-friendly (works from browser directly).

      
Tradier (sandbox + live) — alternative to Alpaca. Sandbox for testing, live for real trades. Get a token at tradier.com/products/brokerage-api.

      
Fidelity (manual only) — no public API for retail accounts. Import positions via CSV export; place trades manually using the copyable order summary. Works fine for long-term holders who want AI research + tracking.

      
Not supported: Robinhood, Schwab, Vanguard, E*Trade — none offer public retail brokerage APIs. Use manual mode (CSV import + copyable order summary) if your broker isn't listed.

    


    

      
Installing on your phone (Android & iPhone)

      
This tool is a PWA (Progressive Web App) — you can install it on your phone's home screen and use it like a native app, even offline.

      
For full install support, you need 2 files on your GitHub Pages site:

      
    
        
  1. REIT_Strategist_v2.html — the app itself
    2. 
        
  2. sw.js — the service worker (enables install + offline use)
    3. 
      

      
Both files must be in the same directory on your GitHub repo. If you only upload the HTML file, the app works in the browser but Chrome won't show the "Install app" option.

      
On Android (Chrome):

      
    
        
  1. Open your GitHub Pages URL in Chrome (e.g., https://yourname.github.io/your-repo/REIT_Strategist_v2.html)
    2. 
        
  2. Wait for the page to fully load
    3. 
        
  3. Tap the three dots menu (⋮) in the top right
    4. 
        
  4. Tap "Install app" (or "Add to Home screen" on older Chrome)
    5. 
        
  5. Confirm — the app appears on your home screen and opens in fullscreen mode
    6. 
      

      
On iPhone (Safari):

      
    
        
  1. Open your GitHub Pages URL in Safari
    2. 
        
  2. Tap the Share button (square with up arrow, at the bottom)
    3. 
        
  3. Tap "Add to Home Screen"
    4. 
        
  4. Tap "Add" — the app appears on your home screen
    5. 
      

      
If "Install app" doesn't appear on Android:

      
    
        
  • Make sure sw.js is uploaded to the same directory as the HTML file
    • 
        
  • Make sure your GitHub Pages site is served over HTTPS (it is by default)
    • 
        
  • Try visiting the page, interacting with it for 30+ seconds, then check the menu again — Chrome has a minimum engagement requirement
    • 
        
  • Clear Chrome's cache for the site and reload
    • 
        
  • As a fallback, "Add to Home screen" always works (creates a shortcut that opens in standalone mode)
    • 
      

    


    

      
Good to know (limitations)

      
    
        
  • This tool runs entirely in your browser — no backend, no server. Your API keys never leave your computer except to call the provider directly (Finnhub, the AI, your broker).
    • 
        
  • If an AI provider is down or blocked by your browser, the tool automatically tries the next one. You'll see which one was used in the output.
    • 
        
  • Finnhub's free tier doesn't include candle price history — the tool falls back to Yahoo Finance automatically. Fundamentals may be partial on free tier; the AI is told what's missing and works with what's available.
    • 
        
  • The AI agents are smart but not perfect. Always verify their output before placing real trades. The verdicts are analysis, not investment advice.
    • 
        
  • Nothing here is investment advice. REIT Strategist is a research tool. You are responsible for your own investment decisions.
